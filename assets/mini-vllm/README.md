# mini-vLLM interface previews

These are browser captures of the working, explicitly labelled mock-LLM teaching page. The terminal, block inspector and pressure scenario are executable local scheduler states, not image-generated app screens or production measurements. All output words and compute time are simulated.

Desktop previews show the full terminal workspace. Portrait inspector previews focus the real inspector while retaining the page's sticky mock notice. Homepage links open the corresponding request/pressure state. The CPU notebook and source remain available separately.
